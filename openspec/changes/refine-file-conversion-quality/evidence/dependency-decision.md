# Dependency decision

Date: 2026-11-03. Decisions distinguish locked source reuse from actual runtime and package measurement. No new production dependency, downloaded font/model or browser runtime is introduced by fixture generation.

| Component | Exact source/version and license | Maintenance/compatibility evidence | Decision and size boundary |
| --- | --- | --- | --- |
| PDF.js / docx / docx-preview | Root package/lock: `6.2.108` Apache-2.0 / `9.7.1` MIT / `0.4.0` Apache-2.0; installed package LICENSE files | Already pinned integration; upstream release recency is not a substitute for Zero's output tests. PDF.js parses all new PDF inputs with complete text. | Reuse. No alternative PDF/DOCX parser or generated-document runtime. Existing engine size evidence must be remeasured after implementation. |
| Tauri / Wry | Cargo.lock `2.11.0` / `0.55.0`, MIT OR Apache-2.0 | Installed Cargo manifests identify Tauri maintained repositories and Rust compatibility; source is locally reviewable. | Reuse current versions. A successful compile alone cannot validate hidden printing. |
| WebView2 COM | `webview2-com=0.38.2`, MIT; transitive `windows=0.61.3`, MIT OR Apache-2.0 | Locked crate source and manifest available locally. COM `ICoreWebView2_7` / `_16` and PrintSettings are a possible runtime interface, with UI STA callbacks. | No bundled WebView2 runtime. Detect the interface on the device. Stage output only. **Do not advertise Windows provider before N02**. Exact host executable delta and runtime-installed version remain unmeasured. |
| Windows font enumeration | Existing direct `windows=0.52.0`, MIT OR Apache-2.0; candidate DirectWrite feature in the same version | Windows platform bindings already in Cargo.lock; 0.52 and WebView2's 0.61 types are separate ABI wrapper families and must not be interchanged. | Prefer OS family enumeration through the existing direct binding, not a new font database/font download. Feature enablement must be explicit and compile-checked. Native enumeration, denial and bounded-list behavior remain separate device checks. |
| macOS font enumeration | System CoreText / AppKit; `objc2-core-text=0.3.2` already transitive, MIT OR Apache-2.0; existing objc/AppKit interop | System framework avoids redistributing a font library. A transitive crate is not automatically an enabled direct API. | Use a narrow platform adapter with bounded family results/deadline and incomplete-inspection report. Direct linking or explicit minimal crate feature must be owned by implementation; no broad font-kit dependency is needed. |
| PDF concatenation | macOS system PDFKit already used; no production `lopdf` or `pdf-lib` in lockfiles | Existing macOS merger can be inspected in native_print.rs. Windows mixed-paper PrintToPdf behavior is untested. | Add **no merger dependency now**. N02 must first prove section/geometry behavior. If one-job mixed paper cannot be preserved, reject explicitly under D03 instead of claiming success. A future merger selection requires a pinned version, notice review and measured delta; it is not implicitly approved by this record. |
| Fixture fonts | Existing embedded Noto Sans SC subset from rich-layout.docx; [OFL notice](../../../../tests/fixtures/fileConversion/assets/OFL.txt) | Embedded bytes are reused and SHA-256 recorded in the quality manifest; no private/system font source. PDF standard Helvetica is used only for ASCII chart/formula labels, including `+` absent from the old subset. | No new distributable font. Fixture DOCX embeds existing subset; scan images use it. Fixture files are not application assets. |
| Python fixture tooling | [exact requirements](../../../../scripts/file-conversion-quality-requirements.txt): python-docx 1.2.0, pypdf 6.21.4, reportlab 5.1.0, Pillow 13.0.0, lxml 6.1.3 | These run outside the product. Existing generator already uses these library families. Reproducibility means two runs with these versions produce identical corpus bytes. | Temporary venv only; excluded from engine/runtime notices and package budgets. No Python conversion provider is introduced. |

No code, font binary or model is downloaded during `--quality-only`; dependencies are installed separately into a local Python environment. Filee, OCR models beyond the existing shared provider, full office suites and remote conversion remain outside this change.

The 20MiB compressed / 45MiB installed engine gates, 2s ready/cancellation deadlines and signed exact identity remain in [release evidence](release-evidence.md). Baseline `preparedAssetInstalledBytes` and gzip values are historical source-asset measurements, not current signed-package size or measured dependency deltas. No unknown size is reported as zero. N02/N03 and R01 remain pending.
