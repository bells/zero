# Acceptance matrix

本文件规定**将来实施的验收要求**，不是已通过的测试记录。所有样本使用生成内容与可分发字体；复用现有 [fixture generator](../../../scripts/generate-file-conversion-fixtures.py)、[expected manifest](../../../tests/fixtures/fileConversion/expected.json)、[OCR fixtures](../../../tests/fixtures/ocr/README.md)，实现时新增受版本管理的合成输入和明确 expected，不读取用户私有文档。

2026-11-03 已新增独立的 [quality expected manifest](../../../tests/fixtures/fileConversion/quality/expected.json)：22 个文档案例、11 个尚未执行的故障/生命周期契约，生成及输入校验见 [fixture evidence](evidence/fixture-contracts.md)。P16 引用旧密码/损坏输入；F03/F04、E01–E09 必须由故障注入或真实生命周期测试执行，D04/P13 也有显式注入前提。`--quality-only` 不改旧 manifest、文件摘要或其旧引擎预期；新 target 不表示当前引擎已经通过。N/R 保持独立待验，R01 所需材料见 [发行证据清单](evidence/release-evidence.md)。

## Support boundary

| 内容 | 本次必须满足 | 允许变化或拒绝 |
| --- | --- | --- |
| 中英正文/标题/段落 | 实际可编辑文字、可靠层级、对齐/缩进、完整顺序 | 字体替换和行换位可警告；无法恢复正文/顺序失败 |
| 常见双栏 | 通栏标题与左右栏不交错 | 任意复杂重叠/多于两栏不作必成承诺 |
| 有框表格 | 可靠文字层+直线网格→真表格，保留行列与支持的合并 | 无边框/扫描表格网格不可靠时可完整重排并提示；内容/顺序不可靠则失败 |
| 插图与局部公式/图表 | 与上下文顺序一致；必要标注完整；非编辑图形有提示 | 不恢复 OMML/chart/数据；不能保留则失败，不整页图片化 |
| 清晰印刷扫描 | 合格本地 OCR→正文可编辑，无重复文字 | 不承诺手写/任意语言；无 OCR/识别失败明确失败 |
| DOCX→PDF | 支持集文字可搜索、图片完整、分页无裁切重叠 | 不承诺 Word 像素等价；混合纸张不能实现则明确 unsupported，不允许错误尺寸成功 |

## Generated output cases

下表 case ID 是验收标识，不表示文件已经存在。生成器必须保存每个样本的正文 token 序列、区域、单元格映射、页尺寸和预期结果；确定性文字提取允许 NFC、明确的空白/换行规范化，不得通过删除正文字符或只查几个关键词制造完整性通过。OCR 的清晰印刷支持语料同样校对完整正文，不据此承诺任意真实扫描零识别错误。

| ID | 合成输入 | 输出断言/检查 | 预期质量/错误 |
| --- | --- | --- | --- |
| P01 | 中文/英文单栏、两级标题、左右对齐与缩进 | DOCX 正文规范化后完整匹配；Paragraph 属性和顺序符合 expected | `editableReconstruction`；重排时有警告 |
| P02 | 通栏标题+两栏论文+页码/页眉 | 顺序为标题→左栏→右栏；页码/页眉内容不丢，不与正文重复 | 无遗漏/交错 |
| P03 | 3 列有框表格，含横向及纵向合并 | `w:tbl`/单元格/列宽/`gridSpan`/`vMerge` 与 expected 一致；每单元格文本一次 | 不得降级成普通段落冒充通过 |
| P04 | 可可靠阅读的无边框表格 | 正文全文和行列阅读序正确；不作原生表格断言 | `tableSimplified` + 源页位置 |
| P05 | 普通插图位于两个段落之间 | 实际 OOXML 为段落→图片→段落；图片关系有效、长宽比/可读尺寸符合 expected | 不允许所有图片都移到页末 |
| P06 | 文字层 PDF 中由矢量绘制的公式、折线图和图例 | 局部图片视觉完整；必要标注在图片中；前后正文仍可编辑且不重复 | `nonEditableGraphic` + 页码；不声称恢复公式/数据 |
| P07 | 局部图形与正文重叠，不能可靠分割 | 不输出残缺 DOCX，不将整页截图作为成功 | `unsupportedInput` |
| P08 | 90/180/270° 旋转的文字页与清晰扫描页 | 正文、表格/图片位置经坐标映射后直立，文字一次 | 有 OCR 则记录 OCR-use |
| P09 | 真空白页、白底扫描空白页夹在正文间 | 空白页保留；正文完整；全空白文档单独拒绝 | 不制造 OCR 错误或虚假正文 |
| P10 | 数字标题+同页扫描正文+独立插图 | 标题/识别正文各一次，插图仍存在，顺序正确 | `ocrUsed`；插图不被无故删除 |
| P11 | 扫描底图已带可靠文字叠层 | 不重复正文，不重复整页底图，必要局部插图保留 | 不额外制造 OCR 正文 |
| P12 | 清晰扫描页含正文和局部图表 | 正文实际可编辑，局部图表及其标注完整保留 | OCR + 局部不可编辑提示 |
| P13 | 某必需扫描区域无法识别/语言不可用 | 前面成功页不形成部分最终输出，下一独立任务可继续 | `ocrRequired` / 识别失败，原因分明 |
| P14 | 纯公式或纯图表且无可编辑正文 | 不塞隐藏文字或虚构标题满足语义门禁 | `unsupportedInput`，不完成图片 DOCX |
| P15 | 旋转/重叠导致无法确定阅读序 | 源文件和已有结果不变，无部分提交 | `unsupportedInput` |
| P16 | 密码 PDF、损坏输入 | 不触发图片回退、模型或云转换 | 保留 password/invalid-input 分类 |
| F01 | DOCX 中确定不存在的 family，及可用替代 | 缺失 family 报告准确；替换仅在已知时指名；文字仍可读 | font/layout 警告，不自动下载字体 |
| F02 | 主题字体、PDF subset、真正可用的内嵌字体 | family 解析与路线可用性正确，无误报 | 不把“嵌入声明存在”当作一定可用 |
| F03 | 字体枚举失败/超限 | 普通可读输出可继续，不声称完整字体匹配 | `fontInspectionIncomplete` |
| F04 | 超过 100 条质量细节/重复位置 | 数量有界，聚合总数/截断标记正确，无正文/路径 | 中英提示一致 |
| D01 | 中英多页 DOCX、页眉页脚、脚注/尾注、插图 | PDF 文字全文、页数/尺寸符合 expected；视觉无漏项 | `webRenderedPdf` 或实际兼容引擎 profile |
| D02 | 跨页长表、边界图片、空白页 | 完整单元格/图片，无裁行、重复或重叠 | 无错误成功 |
| D03 | A4/Letter、横竖混排 section | 每页尺寸/方向匹配；不支持时明确拒绝且无最终文件 | 禁止静默输出统一 Letter |
| D04 | 图片解码失败、字体加载超时、外链资源 | 不生成缺图成功，不隐式请求外链 | 分类资源/timeout/unsupported 错误 |

## Provider and lifecycle cases

| ID | 操作 | 必须观察到的结果 |
| --- | --- | --- |
| E01 | 首次启动、安装了 LibreOffice、内置不可用 | 默认仍为内置且准确不可用；用户显式选择才调用 LO |
| E02 | 选择 Word 后切换 main/tray、语言、重启 | 方向选择保持；标签本地化；重启不恢复文档路径/队列 |
| E03 | 一个方向缺 provider，另一个可运行 | 仅有效方向进入开始批次；无效方向原因清楚，不自动换引擎 |
| E04 | 开始两项 DOCX 批次后更改偏好 | 两项都保留旧绑定；未来未开始任务使用新偏好 |
| E05 | Word 权限拒绝/未激活/卸载/超时 | 原因独立，不启动其他引擎；普通重试保留原选择，显式换引擎重试才改绑定 |
| E06 | 设置写入失败、未知/跨平台旧 provider ID | 保存失败不冒充已记住；无效旧设置明确提示并归一默认，无任意命令执行 |
| E07 | OCR/打包/打印过程中取消或超时 | 无最终提交；过期 token/区域/回调被拒；下一任务不复用仍忙的原生实例 |
| E08 | 源路径不可读、同名输出存在、提交权限不足 | 不改变源文件/旧结果，正确错误和可恢复状态 |
| E09 | 新增 File settings IPC 被 engine/其它窗口调用 | caller/capability 拒绝；不能借设置获得任意文件或进程权限 |
