## 实际功能

- 七工具共享双语注册表，四开发/三图片工具；全部/开发/图片分类、分类内内存搜索、空状态跨分类恢复和独立全工具搜索。普通链接无 JS 可用；语言导航仅保留枚举 category，canonical 无查询。
- 三页共享纯 TS 参数/任务/identity/revision 状态机与文件工作台。选择文件只进行有界字节探测；点击处理才逐张运行专属 Worker。失败继续、仅失败重试、取消保留成功、设置失效旧下载、清空/pagehide/pageshow 清理。
- 显式选中项缩略预览；其后参数编辑仅刷新该预览。预览与批量不并行；每次替换终止旧预览 Worker，输出不超过 400,000 像素。生成缩略输出仍需解码源，不能据此声称源解码只占缩略图内存。
- JPEG/PNG/静态 WebP/HEIC/HEIF 主静态图输入，JPEG/PNG/WebP 输出，HEIC 默认 JPEG。静态签名/容器检查、方向规范化、明确缩小且不放大、JPEG 白底/自选背景、真实质量、体积及无收益显示。
- 单处九宫格/平铺系统文字水印，按最终短边设置比例，最多 500 次绘制；无 Logo、上传字体或逐图排版。小预览字体栅格化与原尺寸下采样可能有差别，预览标明缩略性质。
- PNG 默认无像素变换路径保留方向规范化后的原始采样，含透明 RGB、半透明及 16 位低位；关闭 optimiseAlpha。jSquash 3.1.1 的 16 位编码接口需要显式网络字节序适配。缩放、水印及其他格式转换是显式像素变换，普通工作流为 SDR，不声称色域/HDR 保真。
- 新输出移除 EXIF/GPS/XMP、文本/设备信息及任意 iCCP/ICC 配置；可保留 sRGB/gAMA/cHRM/sBIT 等纯数值渲染提示。丢弃源配置可能改变色彩管理后的外观。原图下载明确保留原始字节/元数据。
- 安全 basename、操作后缀、真实扩展名、大小写重名避让；当前成功项单张或 ZIP 下载。ZIP 有大小预检、计数、取消、超时/失败恢复，全失败禁用。反馈三新线程同时进入站点前端和服务白名单，仍默认关闭且点击后仅发送 threadId/locale。

## 分发、许可与重建

固定依赖仍为 heic-to 1.6.6 来源绑定、libheif 1.23.6/libde265 1.0.16 自建模块、jSquash JPEG1.6.0/WebP1.5.0/PNG3.1.1/oxipng2.3.0、fflate0.8.3 和 image-meta0.3.0。实际生产 HEIC 不导入打包的 heic-to 解码器，而从站点 base 下按需导入独立 `image-codecs/libheif-rebuilt.js`。

`prepare:image-codecs` 校验实验材料的哈希、来源及独立替换证据，原子准备 `public/image-codecs/`。完整 GPL/LGPL/IJG 等通知、原始/对应源码、构建/替换说明及当前应用源代码随 `materials/` 分发，页面有可点击入口；完整运行时模块不加禁止兼容替换的 hash/SRI 检查。材料只显式包含公开源文件/构建文件，不包含 .env、用户文件或浏览器实验页面。

材料中的 `application-source/website/IMAGE_TOOLS_BUILD.md` 给出直接 Astro 构建路径。已将实际随附应用源复制到 `website/output/image-source-proof`，使用固定已安装依赖和替换资源，执行 prepare-social + `pnpm exec astro build` 成功生成 36 页；这证明应用构建材料可用，不代替独立原生解码器重建证据。原始材料清单与替换证明见已有 codec 证据。生成目录、dist、output、node_modules 不提交。

生成的公开源码/asm.js 不应再被 Astro/TS 作为工程源重复诊断；`tsconfig.json` 排除 `public/image-codecs`。未排除时实际触发过 4GiB 检查进程 OOM，修正后正常检查。
