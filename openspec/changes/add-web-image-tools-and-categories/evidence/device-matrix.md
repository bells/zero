# 当前设备实验矩阵

更新：2026-10-18。这是候选编解码器的实验记录，不是已发布工具的支持声明。
变更进度为 5/40（新增纯契约/状态规则 3.1，未接入生产页面）；1.5/1.6、最终工作台下载回归和完整设备验收未完成。

来源：[桌面自动化数据](worker-mobile-preflight.json)、
[iPhone 用户反馈与粘贴结果](iphone-safari-observations.json)。
手机型号 / 系统来自用户截图：iPhone 17 Pro / iOS 27.0.1；Safari 精确版本未采集。
实验使用合成 HEIC 原始字节，不是相机原片，也不是照片选择器转码后的 JPEG。

| --- | --- | --- |

| 桌面 Safari / 相机色彩与 HDR / alpha | Safari 自动化前置条件未开启，用户本轮暂缓；对应验收未完成 | 相机色彩/HDR、alpha 和原始输入/选择器对照未完成 |

总 Worker 时间与已命名阶段之和相差 16.717 秒，包含计时区间之外的未分解工作
（如懒加载），尚无独立剖析；不直接归因于编码。`elapsedMs` 也不是完整主线程
文件读取/下载到输出的端到端计时。

48MP 超时是当前候选与实验期限下的失败，不能据此推导所有 48MP 都不可解码。
12MP 合成流程通过也不能推导所有相机照片或某一手机安全像素上限。当前
32 MiB / 5000 万像素 / 60 秒 / JPEG 质量 75 继续只是实验值。

尺寸属性低报的异常样本还表明：前置探测与 libheif 主图头部尺寸都可能低报，
无法完全约束库内部的分配。资源策略需结合实际测量与异常输入限制再确定。
当前没有新增生产工具、分类入口、部署、提交或规范同步。

2026-10-18 桌面增量：[八场景 RSS 与域契约证据](resource-and-domain-2026-10-18.md)。
