## Why

Zero Snap 当前工具栏靠选区右侧对齐，底部空间不足时先进入选区内部；属性面板打开后才参与高度测量，容易遮挡截图内容或让工具栏跳位。维护者希望优先在选区外居中操作，并能整体拖动工具栏和跟随的属性面板；标注默认红色也能与绿色截图选区边框区分。

## What Changes

- 工具栏按“选区外下方 → 外上方 → 内部底部”排列优先级，以选区中心水平定位，并在屏幕边缘做必要钳制。
- 自动布局提前预留当前视口下所有标注属性面板的最大所需高度；面板关闭、切换工具、工具栏进入手动位置均不触发工具栏因预留空间变化而跳位。
- 下方工具栏的属性面板向下展开，上方或内部底部的属性面板向上展开；自动和手动模式均保留按钮关联箭头。尺寸/圆角条固定贴合选区顶部，不避让手动工具栏。
- 桌面按钮调整为 40×40 CSS px，图标保留 20px，组内间距 2px、组间距和外边距 4px；保留全部工具、分组和窄屏滚动。
- 主工具栏仅保留点阵拖动手柄，双击点阵恢复自动位置（键盘 Enter/Space 同样可恢复），不显示拖动文字或单独复原按钮。拖动时属性编辑面板始终跟随工具栏，属性面板没有独立拖动入口或手动位置。整组位置仅在同一次截图中保留，并受视口边界约束；重新截图恢复自动定位。
- 矩形、椭圆、箭头、画笔、文字的工厂默认色改为已有色板红色 `#ff5252`；选区绿色、已保存颜色、已有标注及马赛克语义保持兼容。重置属性恢复当前工具的工厂默认值，恢复位置不改变样式。

- 标注属性编辑框统一为两行，颜色收敛为红/黄/绿/蓝/黑 5 色加原生自定义颜色入口；所有现有参数和选中对象编辑保留，窄屏以横向滚动访问。

## Capabilities

### New Capabilities

- `snap-floating-panels`: 截图工具栏的紧凑居中布局、稳定空间预留、属性面板双向锚定与工具栏整组会话内拖动。
- `snap-annotation-color-defaults`: 红色工厂默认值、已保存颜色兼容、单工具样式重置及选区绿色边框的区分。

### Modified Capabilities

无。主规范目前仅有 `main-window-shell` 与 `caffeine-duration`，相关 Snap 能力仍在未归档变更中，不能假装主规范已有对应 requirement。

本变更基于 `optimize-screenshot-toolbar` 与 `enhance-snap-annotation-editing` 的已实现行为，明确细化其中的定位次序、面板朝向、密度与工厂色。实施时更新相关代码和测试；将来获准同步/归档时，先处理前置规范，再协调旧规则与本变更，保留不受影响的原场景。本轮不修改历史证据、旧任务或主规范。

## Impact

- 仅涉及 macOS 自定义 Snap 编辑器：`CaptureApp.tsx`、`captureToolbarModel.ts`、`captureGeometryModel.ts`、属性面板及定位 Hook、工具默认值、插件双语文案、相关 `src/App.css` 样式和测试。
- 采用插件内纯几何模型及 React 交互状态，复用现有 ResizeObserver、Pointer Events 和 Lucide 图标；不需要新增运行时依赖。
- 不增加 Rust command、IPC 字段或持久化位置配置；既有 `zero.snap.annotation-defaults.v1` 数据格式继续兼容。
- Windows 继续使用系统截图入口；本轮不扩展 Linux、移动端、多屏采集能力或其他插件。
- 验收分开记录纯模型/浏览器验证与真实 macOS `pnpm tauri dev` 操作；截图媒体、导出与 OCR 契约保持现有边界。
