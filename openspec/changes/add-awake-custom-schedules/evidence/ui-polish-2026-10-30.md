# Awake UI polish · 2026-10-30

The maintainer approved a quiet, compact, native-aware direction after reviewing the main workspace and battery-preference screenshots.

## Implementation

- `CaffeinePanel.tsx`: separate status and plan regions. Presets and custom editing occupy the same region. “Back to presets” cancels without mutation. A custom editor has one primary submit action and retains a secondary stop action for a live session. Keep busy guards, focus restoration and the native-menu editor revision contract.
- `caffeine.css`: smaller neutral status ring; finite sessions show remaining time in the ring, while unlimited sessions show elapsed time. Avoid duplicate main-window timing. Compact tray controls, 44px primary actions, shared input styles, visible keyboard focus, restrained state colors.
- `AwakeSettings.tsx`: reuse the host's preference section/group/row/switch vocabulary and 720px content limit. Group the threshold under its toggle, show one percentage, and distinguish Save from Read again. Preserve the existing search target IDs and unavailable/error states.
- `i18n.ts`: Chinese/English labels for schedule navigation and mode selection, with Start Awake / Stop Awake / Apply schedule actions.

No dependency, Rust source, session hook, IPC contract or power-policy change. No commit, push or archive is included.
