## Why

官网在线工具目前只提供 GitHub Issues 入口，临时使用工具的游客需要额外登录才能留下问题、改进建议或新工具需求。增加免登录、先审后公开的反馈入口，可以收集真实需求并公开站长回应，同时保持工具输入在本地处理的承诺。

## What Changes

- 在双语在线工具目录与当前四个在线工具页增加“反馈与建议”入口：目录承接整体建议与新工具需求，子页关联对应工具，同一工具的中英文共享反馈。
- 用户点击后，在当前页展开独立来源 iframe；未点击不请求反馈站点，不自动读取或传递工具输入、输出、文件、搜索词及草稿。
- 游客无需注册或登录；昵称、邮箱均可选，邮箱仅供站长私下联系且不公开。首版支持有界纯文字反馈和经认证的站长回复，全部内容先审核再公开。
- 复用 Waline 的评论存储、审核后台与 JSON 导出；为匿名字段、纯文本、站长回复权限、公开字段裁剪和隔离嵌入增加明确适配，不直接嵌入默认评论组件。
- 首选 Vercel Functions + Neon PostgreSQL；启用前核验实际账号套餐、用途限制、免费额度与安全配置。以零新增费用起步，不能满足则保持入口未启用并重新选型，不自动开通付费资源。
- 提供双语待审核、失败、超时、限流和未配置状态；评论不可用时工具照常运行。形成手动审核、升级、配额检查、导出备份与恢复的维护流程。
- 首版不包含图片/文件附件、点赞投票、访客互相回复、多层讨论、自动邮件通知、自动翻译、反馈状态看板或桌面功能。

## Capabilities

### New Capabilities

- `web-tools-feedback`: 双语入口、目录与工具线程、匿名表单、公开列表和失败反馈。
- `isolated-feedback-boundary`: 点击后加载、跨来源嵌入、最小消息契约、计算内容隔离及资源预算。
- `moderated-feedback-service`: 服务端校验与审核、站长回复、公开数据裁剪、抗滥用、可导出存储及启用门禁。

### Modified Capabilities

无。当前 `openspec/specs/` 仅有桌面 shell 与 caffeine 规范；官网和在线工具规范仍在未归档变更中。本变更新增独立规格，不伪造对尚未同步主规范的 MODIFIED delta，也不顺带同步或归档其他变更。

## Impact

- 官网预计涉及 `website/src/components/webTools/Page.astro`、反馈专属组件/脚本/样式、双语内容、按环境启用配置、浏览器隐私回归与网站维护文档。Astro 主站继续静态构建，现有计算层、worker 和桌面文档路由保留。
- 新增与 `website/`、`src/`、`src-tauri/` 分离的 `feedback/` 服务工程，包含独立来源的反馈页面、Waline 适配及部署/存储配置；依赖版本、许可证、维护状态与扩展点在实施前锁定验证。
- 新增隔离来源的访客读写 API 与认证管理员操作；不新增 Tauri command、Rust/TS IPC、桌面依赖或桌面数据采集。
- 依赖 `add-zero-product-website`、`usezero-web-tools-extension` 与 `extend-web-tools-batch-and-diff` 的现有路由、双语、隐私及性能基线；仅主动提交的反馈进入新增服务，既有工具内容本地处理约束不放宽。
- 本次只交付提案与规格。真实云账号、免费套餐资格、所选 Waline 发布版本、托管响应头和跨站浏览器行为仍需后续分别验收；生成提案不创建云资源、不改 DNS、不部署。
